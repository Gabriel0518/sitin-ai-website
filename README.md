# Sitin.ai Website

Static bilingual homepage for Sitin.ai, including the Sitin.ai, Sitin.ai Creator, Sitin.ai Business and Growth Agent product story.

## Run locally

Open `index.html` directly, or serve this directory with any static web server.

## Assets

- `hero-video.mp4`: looping homepage Hero background video.
- `hero-video-poster.png`: poster shown while the video loads or reduced motion is enabled.
- `sitin-ai-business-dashboard.png`: Sitin.ai Business product preview.
